# 照片选片 0.9.0-beta.2

- 设置新增「软件更新」：从本仓库 GitHub Releases 检查版本、查看说明、下载安装包并更新。显示下载进度和速度，支持取消及断点重试。
- 仅接受本仓库的 Windows x64 安装器，并校验 GitHub 提供的 SHA-256 摘要。安装期间不允许启动新的工作流；已有任务未完成时不能安装。
- 完成下载后点击「退出并安装更新」，更新完成自动打开程序。沿用原安装目录，保留数据目录、工程和模型。
- 修复数据目录位于安装目录内时的更新保留逻辑；归还数据失败时停止清理并保留备份。
- 包含之前已提交的分组拖动排序、边缘自动滚动和云端视觉模型通用配置（百炼 / OpenAI 兼容接口）。云端仍为混合模式，不替代所有本地模型或 Lightroom。

## 安装与升级

下载 `PhotoAI-Setup-x64.exe` 覆盖安装即可。旧 beta.1 没有软件内更新入口，本次仍需手动安装；从此版本起可在设置中获取后续更新。

安装包不含 AI 模型。已有模型和工程无需删除；如果启用云端后提示计算环境需要更新，在资源页重新配置当前档位，可复用已下载模型。

本版为 Windows x64 测试版，未进行 Authenticode 签名。云端真实调用需要用户自己的 API Key。
