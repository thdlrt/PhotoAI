# 照片选片 0.9.0-beta.4

- 修复软件内更新时“无法暂存当前版本”的一种明确原因：数据目录位于安装目录内时，旧更新助手的工作目录、运行中的安装包或 TEMP/TMP 会占用待改名的程序目录。
- 安装前先校验并复制安装包到程序目录外的专用暂存目录，更新助手、安装器及 TEMP/TMP 全部在外部运行。原下载缓存保留。
- 安装器会短暂等待退出后的占用释放；仍无法暂存时返回失败状态，保留旧版和数据，并提示把安装包放到程序目录外后重试。
- 已修复的 beta.3 AI Worker 可继续使用，无需仅为本次桌面更新重新配置；更早、尚未修复的 AI Worker 仍需在资源页修复当前档位。
- 包含 beta.3 的置信度范围、带错误反馈的重试及单张/批量照片删除功能。

## 当前安装失败的升级方法

旧 beta.2 / beta.3 更新助手中的目录占用问题，不能靠反复点击同一个软件内安装按钮解决。

1. 退出失败的安装窗口和照片选片。
2. 从本页下载 `PhotoAI-Setup-x64.exe`，保存到“下载”目录等程序目录之外的位置。
3. 运行安装包，覆盖安装到原目录。不要删除旧程序、数据目录或 `.photoai-previous` 备份。
4. 如果仍提示占用，关闭打开该目录的资源管理器、终端或其他程序后重试。真实外部占用仍会阻止更新，本版不会强制结束未知进程或删除旧数据。

Windows x64 测试版，未进行 Authenticode 签名；安装包不包含 AI 模型。
