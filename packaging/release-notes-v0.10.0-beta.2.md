# 摄影后期工具箱 0.10.0-beta.2

## 视频整理 · 帧选

- 工具箱首页新增帧选入口，安装包包含 FramePick 1.2.0 和所需 .NET/WPF 运行组件。
- 创建或打开 .framepick 项目，每次导入一个文件夹，可累计多个；分类、目标目录和整理进度跟随项目。
- 带时间标记的 16 帧预览、搜索排序、项目隔离、预览重试、停止后继续、重名保护与回收站。
- 缓存、配置和默认项目保存在工具箱数据目录；复用随附 FFmpeg，不重复打包媒体工具。
- CLI 新增 tools framepick-status 和 tools framepick-open，窗口以独立进程启动。

本版同时发布此前完成的 0.10.0 工具箱升级：交互审片、AI 剪辑草案、LRTLite 延时摄影和统一 CLI。原有选片工程、星级、人工分组和未知扩展字段保留；已退休的构图/调色工作流不重新启用。

## 下载与验证

下载 PhotoAI-Setup-x64.exe，可沿用现有安装与数据目录；完整工具包不含 AI 模型权重。安装器约 447.6 MiB。

235 项相关回归通过：工具箱 128 项、桌面 22 项、帧选 50 项核心与 35 项界面。安装器提取后的真实 Service、CLI、旧工程只读、媒体工具与组件载荷检查通过，首页点击已实际启动随包帧选。

本次使用隔离的合成素材；没有覆盖真实用户安装或原片。2 GiB 扩展样例验证大文件寻址，不代表长片性能。仍为 beta 发行，未追加干净 Windows VM 或真实照片审美质量验收。
