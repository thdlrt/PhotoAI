# 照片选片 0.9.0-beta.3

- 修复“构图组内评审”中的置信度范围歧义：七项照片评分使用 0–100，`confidence` 明确使用 0–1，例如 90% 应返回 `0.9`。
- 模型回复校验失败后，重试会附带具体照片 ID、字段、收到的值和校验错误。保留严格校验，不会把未知数值强行转换成有效置信度。
- 失败回复和错误详情保存在数据目录的 `logs/vlm-validation` 中，便于排查；记录有长度限制，不保存请求图片或 API 密钥。
- 更新视觉评审缓存版本；已有照片读取、相似特征和通用审美缓存继续保留。
- 选片界面新增单张和批量“删除”：确认后将源文件移入照片目录内 `.photo-ai-trash/selection` 回收区，刷新分组。原有“移出”仍只影响工程记录。
- 保留旧工程及人工分组、评分等调整；删除失败时尝试恢复已移动文件，并留下操作记录。

## 另一台电脑的升级步骤

1. 在设置中检查软件更新，或下载 `PhotoAI-Setup-x64.exe` 覆盖安装到原目录。
2. AI Worker 与桌面程序分别安装。更新后如资源页提示计算环境需要更新，在当前 8GB / 16GB 档位点击“补齐并修复”，等待配置和自检完成；沿用已有模型和数据目录，无需删除工程、原片或模型。
3. 重新运行失败的 AI 评分。此版本会阻止旧 Worker 继续执行；仅覆盖桌面安装包或在旧版点击“重试”不足以修复此问题。

安装包不包含 AI 模型。Windows x64 测试版，未进行 Authenticode 签名。
已通过构造 `confidence=90` 后纠正为 `0.9` 的重试回归；另一台电脑的 95 张照片尚未在本机复跑。
