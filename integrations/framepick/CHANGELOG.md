# FramePick 1.2.0 · 2026-11-03

- 新增创建、打开 .framepick 项目；分类、目标目录、预览并发数与整理决定归属当前项目。
- 项目内每次导入一个文件夹，可逐次累计导入多个目录；重复及重叠目录按视频完整路径去重。
- 切换或重开项目时恢复各自进度，同一素材在不同项目中的决定彼此独立。
- 项目自动保存并保留 .bak 上次版本；损坏文件不会替换当前项目，无法保存时阻止关闭以保留当前状态。
- 目录暂时离线时保留决定；恢复后可以继续整理。
- 提供显式的旧版分类与进度导入，保留原始旧配置。
- 增加项目存储、项目隔离与重复导入回归；测试根目录可配置，不依赖开发机路径。

# FramePick 1.1.0 · 2026-11-03

- 修复添加分类时两处非法 Margin 引发的连续异常弹窗。
- 修复主窗口和分类窗口没有实际应用主题，导致标题和正文在深色背景上显示为黑色。
- 重做分类导航、搜索排序、预览卡片、任务进度、底部操作汇总与详情界面。
- 分类编辑支持正常输入空格、浏览目标文件夹和内联校验；保存设置保留已有分类决定。
- 修复分类下拉框显示内容模板，使用完整预览比例和深色滚动条、标题栏。
- 修复预览任务取消状态与资源清理，生成中允许翻页；支持停止后继续和失败重试。
- 修复批处理中途停止丢失已完成结果的问题，关闭执行中的窗口会先请求停止。
- 修复损坏的预览缓存误判为有效、短视频定位后无帧，以及详情加载与筛选切换的问题。
- 分类自动保存合并写入，退出时立即保存；文件发生变化后不再应用该文件旧的决定。
- 增加核心与 WPF 回归检查；使用独立合成样例验证，不操作用户原始视频。

验证范围：合成常见容器、单帧竖屏、2 GiB 扩展样例；移动、重名保护、回收站、取消；分类增改保存、搜索筛选、分页、详情与主题文字。2 GiB 样例用于验证大文件寻址，不代表长时长真实素材性能测试。
